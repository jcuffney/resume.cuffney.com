## Homelab deployment (`deploy/`)

The public `https://resume.cuffney.com` is served from the homelab v2 cluster:
`deploy/` holds Kustomize manifests that Argo CD applies into namespace
`resume` (this replaces the v1 gateway vhost, which served the same PDF from
the homelab Ansible role). The Next.js site above and its AWS workflow
(`primary.yml`) are untouched.

- `deploy/resume.pdf` is the published PDF; nginx (`nginx:1.30.4-alpine`, unprivileged) serves it inline at `/` from a ConfigMap generated by kustomize. Replace the file and push to `main` to publish — the ConfigMap hash changes and the Deployment rolls.
- `deploy/ingress.yaml` is class `external` with the `external-dns.alpha.kubernetes.io/target` tunnel annotation: replace `TUNNEL_ID` with the Cloudflare tunnel UUID (manual-setup step 2.1) before the first sync.
- `.github/workflows/ci.yml` renders `deploy/` with kustomize and checks it with kubeconform on PRs; nothing in CI touches the cluster.

Tenant contract: topic `homelab` + `deploy/kustomization.yaml` opt the repo in; namespace = repo name minus `.cuffney.com`; `ingressClassName: internal` (LAN/VPN) or `external` + tunnel target (public); storage classes `longhorn` / `nfs-media` / `nfs-backups`; secrets via `ExternalSecret` from 1Password.
